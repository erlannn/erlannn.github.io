Website Marketplace Sulam

Marketplace Sulam adalah website jual beli produk sulaman yang dibangun menggunakan Laravel. Platform ini memudahkan pelanggan dalam mencari dan membeli produk, serta membantu admin mengelola produk dan transaksi secara efisien. Website ini menggunakan Spatie Permission untuk mengatur hak akses pengguna, Tailwind CSS untuk menciptakan tampilan yang modern dan responsif, serta Fonnte WhatsApp Gateway untuk mengirimkan notifikasi transaksi secara otomatis kepada pelanggan.

Website Menara Sumbar

Website ini dibangun untuk tujuan menyediakan informasi tentang Base Transceiver Station (BTS) kepada pengunjung, pada website ini mempunyai peta yang menampilkan lokasi BTS lengkap dengan jangkauan jaringan dan sudah memiliki fitur geotagging untuk mengetahui apakah pengguna berada dalam jangkauan jaringan.

Website E-Commerce Solvibe

Solvibe adalah website E-Commerce yang dibangun menggunakan Laravel + Spatie Permission + Tailwind untuk memudahkan proses jual beli secara online. Melalui website ini, pengguna dapat melihat katalog produk, mencari barang, menambahkan produk ke keranjang, dan melakukan pembelian dengan mudah. Sementara itu, admin dapat mengelola produk, stok, dan transaksi melalui dashboard yang terintegrasi.
